Project description: A platform where remote workers discover and book coworking spaces,  cafes and work-friendly spots globally.

Design ideas: Clean, productive aesthetic, map-based space finder, amenity filter tags, workspace photo galleries, hot desk booking flow. 

Problem Statement:

Remote workers and digital nomads frequently struggle to find reliable, work-friendly spaces with essential amenities like high-speed wifi, power outlets, and quiet environments. The current discovery process is fragmented and inefficient, forcing users to rely on trial and error or inadequate search tools that lack real-time space availability, clear visual previews, and direct reservation options. Treehouse addresses this by providing a unified, map-based platform that allows professionals to easily discover verified cafes and coworking hubs worldwide, filter spaces by specific productivity amenities, view photo galleries, and book hot desks seamlessly in one place.
